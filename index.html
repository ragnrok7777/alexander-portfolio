01 / About Me

Building with clarity, curiosity, and purpose.

I’m an IMCA student focused on creating modern web products that feel effortless to use and solid under the hood.

My developer journey began with curiosity about how websites turn ideas into interactive experiences. Starting with semantic HTML, expressive CSS, and vanilla JavaScript, I naturally expanded into backend development with Python, Flask, and REST APIs so I could build complete end-to-end applications.

I enjoy combining visual polish with practical engineering — whether that means integrating third-party APIs like TMDB and AniList, designing responsive interfaces, or experimenting with AI-powered features that make discovery smarter.

Interests

Clean UI/UX design, full-stack web architecture, RESTful API integrations, and interactive AI-assisted web applications.

Ambitions

Growing into a well-rounded full-stack engineer capable of shipping scalable, user-centered products from concept to production.

04 / Developer Journey

Milestones along the learning curve.

A look at how my skills evolved from writing my first HTML tags to building complete full-stack applications.

  1. Stage 01 · Foundations

    Discovering Web Structure & Visual Design

    Started learning HTML5 and CSS3 from the ground up — mastering semantic layouts, typography, Flexbox, CSS Grid, and responsive design principles.

  2. Stage 02 · Interactivity

    Bringing Interfaces to Life with JavaScript

    Built interactive browser experiences using vanilla JavaScript, focusing on DOM manipulation, asynchronous fetch calls, and smooth user interactions.

  3. Stage 03 · Backend Engineering

    Stepping into Python, Flask & REST APIs

    Expanded beyond the browser by building server-side routes, structured backends, and external API integrations with Python and Flask, tracked cleanly with Git and GitHub.

  4. Stage 04 · Full-Stack Build

    Launching CineBot 3.0

    Combined frontend craft and backend API orchestration to create CineBot 3.0 — integrating TMDB, AniList, external anime watch links, and an AI-powered chatbot into a single responsive entertainment platform.

  5. Present & Next

    Advancing Toward Full-Stack Mastery

    Continuing to refine UI/UX sensibility, deepen backend architecture skills, and build impactful projects while preparing for future developer opportunities.
